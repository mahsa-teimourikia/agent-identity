# Security Policy

## Supported Versions

Since this project primarily consists of educational curriculum and labs, we only actively maintain and support the latest version available on the `main` branch. 

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within this project (for example, insecure dependencies in the `pyproject.toml`, exposed credentials in the curriculum examples, or XSS vectors in the UI), please do not open a public issue.

Instead, please send an email to the repository owners directly. We will strive to acknowledge your report within 48 hours and will provide a timeline for addressing the issue.

### What to Include
When reporting a vulnerability, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact or risk.
- Any suggested mitigations or fixes, if applicable.

We appreciate your help in keeping this educational repository safe for all users!
