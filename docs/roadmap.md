# Learning roadmap

## Beginner

Identity context, principal types, authentication versus authorization, RBAC, deny-by-default, and typed tools. Outcome: reject wrong issuer, audience, tenant, and expiry.

## Intermediate

OAuth scopes and token exchange, ABAC/ReBAC, risk scoring, approvals, audit events, and revocation. Outcome: down-scope a specialist token without escalation.

## Advanced

Delegation chains, key lifecycle, kill switches, threat modeling, evaluation, and production readiness. Outcome: operate a multi-agent identity plane with measurable release gates.
